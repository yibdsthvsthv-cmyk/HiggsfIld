# HiggsfIld

A free AI code generator web app that runs with local Ollama.

## Features
- Web UI
- Local AI backend
- No paid API key required
- Copy generated code button
- Multiple language support

## Requirements
- Node.js
- Ollama

## Install Ollama
Download and install from: https://ollama.com

Then run:

```bash
ollama pull llama3.2
npm install
npm start
```

Open http://localhost:3000
